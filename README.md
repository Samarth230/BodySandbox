**Body Sandbox** — Medical Simulation Platform
Body Sandbox is an interactive web-based simulation tool designed for visualizing and analyzing health parameters, medical conditions, and system effects in real time. Below are prototypes representing different stages and styles of the platform’s interface.

**Overview**
Body Sandbox enables users to adjust patient parameters, apply condition presets, simulate drugs or treatments, and monitor vital signs through an interactive 3D anatomy interface. The platform is built using Vue.js, modern charting libraries, and integrates real-time feedback mechanisms for an engaging medical educational experience.

**Features**
Adjustable health presets (Healthy, Obesity, Diabetes, Anemia, etc.)

Real-time control of body parameters (age, body fat, blood sugar, blood pressure)

Interactive 3D anatomical models with organ highlights

System-based filtering (Cardiovascular, Digestive, Nervous, etc.)

Live vital sign monitoring and visualization (heart rate, BMI, oxygen saturation)

Export and data management tools

Analytics dashboard for trends and system status

*Prototype Screens**
1. Dark Mode Simulation Panel

Focused on a dark theme for enhanced contrast and immersive simulation.

Preset selection for quick setup of medical conditions.

Real-time sliders for age, body fat, blood sugar, and blood pressure updates.

Central 3D figure for basic anatomical simulation.

Panel for vital signs and circular health assessment.

Bottom charts for trends in heart rate, blood pressure, and system health.

2. Demo Sandbox UI

Modern, minimalist interface for demonstration purposes.

Large, attention-grabbing preset box for medical condition selection.

Interactive 3D body with organ overlays, draggable and zoomable.

Standard card components for quick parameter review (heart rate, blood pressure, body temp).

Simple navigation for technology showcase.

3. Real-Time Anatomy Simulation

Comprehensive simulation dashboard for patient parameter adjustment.

Integrated drug selection and effect simulation panels.

Detailed organ analysis system with system-level filters.

Anatomical model for visualizing drug impact on organs.

Parameter summary and auto-calculated BMI.

Export, save, and session management for advanced studies.

4. Analytics & Monitoring Dashboard

Home screen with quick access to all platform modules (Anatomy, Analytics, Profiles, Emergency, Nutrition).

Central vital signs monitor with live data updates.

Time-series graphs for heart rate variability and blood pressure trends.

Status overview for systems and immediate health alerts (e.g., elevated glucose).

Integrated auto-refresh and real-time feedback.

**Technology Stack**
Vue.js (core SPA framework)

Vuex / Pinia (state management)

Chart.js / D3.js (for graphical analytics)

Three.js or SVG/Canvas (3D anatomy visualization)

RESTful API or WebSockets (live data updates)

SCSS / Tailwind (responsive modern styling)
